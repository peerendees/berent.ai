Die ideale Website-Struktur laut Kris:                                                                                                                                                                       
                                                                                                                                                                                                               
  ┌─────┬────────────────────────────────────┬──────────────────────────────────────────────────────────────────────────┐                                                                                      
  │  #  │              Sektion               │                                  Zweck                                   │                                                                                      
  ├─────┼────────────────────────────────────┼──────────────────────────────────────────────────────────────────────────┤                                                                                      
  │ 1   │ Hero-Sektion                       │ Klarheit (5-7 Worte), Emotion (Foto), Trust-Symbole (Logos, Zahlen), CTA │                                                                                      
  ├─────┼────────────────────────────────────┼──────────────────────────────────────────────────────────────────────────┤
  │ 2   │ Problembewusstsein                 │ Zielgruppe abholen mit deren eigenen Worten, Aha-Effekt auslosen         │                                                                                      
  ├─────┼────────────────────────────────────┼──────────────────────────────────────────────────────────────────────────┤                                                                                      
  │ 3   │ Losungsbewusstsein / Wunschzustand │ Zeigen, was nach der Zusammenarbeit moglich ist                          │                                                                                      
  ├─────┼────────────────────────────────────┼──────────────────────────────────────────────────────────────────────────┤                                                                                      
  │ 4   │ Testimonials (Social Proof)        │ Video + Text, min. 3 je Format, je langer desto besser                   │
  ├─────┼────────────────────────────────────┼──────────────────────────────────────────────────────────────────────────┤                                                                                      
  │ 5   │ Mehrwert-Bereich                   │ 3 beste Artikel/Posts, Expertise untermauern                             │
  ├─────┼────────────────────────────────────┼──────────────────────────────────────────────────────────────────────────┤                                                                                      
  │ 6   │ Uber mich                          │ Personliche Story mit Bezug zum Thema, echte Fotos                       │
  ├─────┼────────────────────────────────────┼──────────────────────────────────────────────────────────────────────────┤                                                                                      
  │ 7   │ Grosser CTA                        │ Finale Terminbuchung mit Trust-Elementen                                 │
  ├─────┼────────────────────────────────────┼──────────────────────────────────────────────────────────────────────────┤                                                                                      
  │ 8   │ FAQ                                │ Einwandvorwegnahme und Vorqualifizierung                                 │
  ├─────┼────────────────────────────────────┼──────────────────────────────────────────────────────────────────────────┤                                                                                      
  │ 9   │ Danke-Seite (nach Buchung)         │ Vertrauen starken, Abschlussquote erhohen                                │
  └─────┴────────────────────────────────────┴──────────────────────────────────────────────────────────────────────────┘                                                                                      
                  
  Kernprinzipien:                                                                                                                                                                                              
                  
  - Vertrauen ist das A und O - Trust-Elemente mussen sofort sichtbar sein (vor dem Scrollen)                                                                                                                  
  - Testimonials sind das Fundament - lieber 3 ausfuhrliche als 10 kurze
  - Navigation: max. 5 Menupunkte + CTA                                                                                                                                                                        
  - Hero: Keine Slider, keine Animationen, keine Uberladung                                                                                                                                                    
  - CTA aus Sicht des Lesers formulieren (z.B. "Ich will planbar Kunden gewinnen")                                                                                                                             
  - Nach Fertigstellung: nicht standig andern, sondern Fokus auf Content und Akquise
