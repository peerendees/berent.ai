GitHub — Häufige Fragen

Antworten auf die häufigsten Fragen zu GitHub: Grundlagen, Kosten, Einstieg, Recht und Datenschutz — für Einsteiger und Mittelständler.

Grundlagen

Was ist GitHub?

GitHub ist eine Cloud-Plattform, auf der du Dateien und Programmcode speicherst, ihre Änderungshistorie lückenlos nachverfolgst und gemeinsam daran arbeitest. Technisch baut GitHub auf dem Versionsverwaltungssystem Git auf und ergänzt es um Werkzeuge für Planung, Zusammenarbeit und Automatisierung.

Quelle: https://docs.github.com/de/get-started/start-your-journey/about-github-and-git · Stand: 2026-07-24

Was ist der Unterschied zwischen Git und GitHub?

Git ist das Versionsverwaltungssystem: Es läuft auf deinem Rechner und verfolgt Änderungen an Dateien. GitHub ist die Plattform darüber — sie hostet deine Git-Projekte in der Cloud und ergänzt Zusammenarbeit, Reviews und Automatisierung.

Kurz: Git funktioniert auch ohne GitHub. GitHub ohne Git nicht.

Quelle: https://docs.github.com/de/get-started/start-your-journey/about-github-and-git · Stand: 2026-07-24

Was ist ein Repository?

Ein Repository (kurz „Repo") ist das grundlegendste Element von GitHub: der Ort, an dem deine Dateien samt vollständiger Änderungshistorie liegen.

Ein Repository kann öffentlich sein — dann ist es für jeden im Internet sichtbar — oder privat: Dann haben nur du und die Personen Zugriff, denen du ihn ausdrücklich gibst.

Quelle: https://docs.github.com/de/repositories/creating-and-managing-repositories/about-repositories · Stand: 2026-07-24

Was ist ein Pull Request?

Ein Pull Request ist ein Vorschlag, Änderungen zusammenzuführen. Das Team kann die Änderung besprechen und prüfen, bevor sie übernommen wird.

Das ist GitHubs zentrales Werkzeug für Zusammenarbeit: Fehler fallen früh auf, und jede Änderung hat eine nachvollziehbare Begründung.

Quelle: https://docs.github.com/de/pull-requests/collaborating-with-pull-requests/proposing-changes-to-your-work-with-pull-requests/about-pull-requests · Stand: 2026-07-24

Kosten und Pläne

Was kostet GitHub?

Der Einstieg ist kostenlos. GitHub Free enthält unbegrenzte öffentliche und private Repositories, unbegrenzte Mitarbeiter in öffentlichen Repositories, 2.000 GitHub-Actions-Minuten pro Monat, 500 MB Paketspeicher sowie ein monatliches Codespaces-Kontingent.

Private Repositories haben im kostenlosen Plan einen eingeschränkten Funktionsumfang. Erweiterte Team-Funktionen gibt es in den kostenpflichtigen Plänen.

Quelle: https://docs.github.com/de/get-started/learning-about-github/githubs-plans · Stand: 2026-07-24

Kann ich private Repositories kostenlos nutzen?

Ja. Private Repositories sind im kostenlosen Plan unbegrenzt möglich — allerdings mit eingeschränktem Funktionsumfang.

Wer in privaten Repositories Dinge wie erzwungene Review-Freigaben oder geschützte Branches braucht, benötigt einen kostenpflichtigen Plan.

Quelle: https://docs.github.com/de/get-started/learning-about-github/githubs-plans · Stand: 2026-07-24

Einstieg

Brauche ich Programmierkenntnisse, um GitHub zu nutzen?

Nein. Für viele Anwendungsfälle reicht der Browser: Dateien hochladen, Texte direkt bearbeiten, Änderungen nachvollziehen.

GitHub wird längst nicht nur für Programmcode genutzt, sondern auch für Dokumentation, Checklisten, Vorlagen und Wissenssammlungen — überall dort, wo mehrere Menschen an denselben Dateien arbeiten und die Historie zählt.

Quelle: https://docs.github.com/de/get-started/start-your-journey/about-github-and-git · Stand: 2026-07-24

Muss ich Git auf meinem Rechner installieren?

Für einfache Aufgaben nicht — Dateien anlegen und bearbeiten funktioniert direkt im Browser.

Sobald du lokal arbeiten willst (viele Dateien auf einmal, Arbeit ohne Internet, größere Änderungen), installierst du Git zusätzlich auf deinem Rechner.

Quelle: https://docs.github.com/de/get-started/start-your-journey/about-github-and-git · Stand: 2026-07-24

Recht und Datenschutz

Wem gehört der Code, den ich hochlade?

Dir. Ohne Lizenz gilt das übliche Urheberrecht: Du behältst alle Rechte, und andere dürfen deine Inhalte weder kopieren noch weiterverbreiten.

Wichtig bei öffentlichen Repositories: Die GitHub-Nutzungsbedingungen erlauben anderen unabhängig davon, dein Repository anzusehen und zu forken. Wenn andere deinen Code aktiv nutzen dürfen sollen, brauchst du eine passende Lizenz.

Quelle: https://docs.github.com/de/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository · Stand: 2026-07-24

Lässt sich GitHub DSGVO-konform im Unternehmen einsetzen?

Ja — mit den üblichen Hausaufgaben. GitHub stellt eine Auftragsverarbeitungsvereinbarung bereit und stützt Datenübermittlungen in die USA auf Standardvertragsklauseln.

Für den Unternehmenseinsatz heißt das konkret: Vereinbarung abschließen, die Verarbeitung im Verzeichnis dokumentieren und vor allem prüfen, welche personenbezogenen Daten überhaupt in Repositories landen — im Idealfall gar keine.

Das ist eine praktische Einordnung, keine Rechtsberatung.

Quelle: https://docs.github.com/de/site-policy/privacy-policies/github-data-protection-agreement · Stand: 2026-07-24
